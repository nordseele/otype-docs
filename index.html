Reading a line

One command per line, in prefix notation: an operation takes the values that follow it, which may be operations themselves. Modifiers before : repeat or condition the rest of the line; a line ending with : opens an indented block.

L 1 16: PROB 35: TR.ADD I        # for I = 1..16, 35 % chance: a trig on step I
PL.SET I AMP.VOL RRAND 70 127    # = PL.SET (I) (AMP.VOL) (RRAND 70 127)
STEPS HAS.TRIG:                  # block: the steps that have a trig
  EACH: COND.SET I 50%

Dotted names (TR.ADD) are the OT's API; your own functions use underscores and take their arguments after |. Check scripts on the computer with python3 tools/otype.py check FILE.OTY.

Argument letters

sstep, 1..64
ttrack, 1..8
nsample slot, 1..128
pparameter, 0..29 — written PB 1, LFO 3, AMP.VOL, FX1 2…
vvalue, clamped to the parameter's range
ctrig condition: 50%, 1:4, FILL, !PRE… or a number
k n rhits, length, rotation of a rhythm
ffile number in the current DIR list
x y znumbers (16-bit, saturating)

No command matches this filter.

Structure

OTYPE 1
language version, first line of a file (optional)
DEF NAME [| ARG ...]
define a function (a brick when it has no MENU); body indented below
CONST NAME value
file-level constant (number, string, list or condition), global to all files
MENU "LEVEL" >> "ACTION"
place of the function in the popup (levels up to 6 chars, action up to 10)
PARAM NAME default min max
a setting editable on the unit, read like a constant
CONFIRM ["TEXT"]
ask YES/NO before running (implied by destructive operations)

Modifiers

IF c: ...
run the line or block when c is true
ELIF c: ...
after an IF/ELIF at the same indentation: another condition
ELSE: ...
after an IF/ELIF at the same indentation: the remaining case
L a b: ...
loop I from a to b inclusive; bounds are constant (never a variable)
EACH: ...
for each step of the context, in order (I = the step)
PROB p: ...
run with p percent probability
EVERY n: ...
run once every n passes over this line
SKIP n: ...
run every time except once every n passes
DEL n: ...
reserved: run n steps later (not available yet)

Flow

BREAK
leave the innermost loop (L or EACH)
STOP
leave the function
RET [v]
leave the function, giving the value v (the function then works as a value)

Keyword arguments

ALL
keyword argument: every track or every step (TRK ALL, STEPS ALL)
CUR
keyword argument: the current track (TRK CUR)
DEEP
keyword argument of DIR: include subfolders

Variables

A
local to one run of the function, 0 at start; assignable
B
local to one run of the function, 0 at start; assignable
C
local to one run of the function, 0 at start; assignable
D
local to one run of the function, 0 at start; assignable
X
global, shared, kept from one press to the next, 0 at boot; assignable
Y
global, shared, kept from one press to the next, 0 at boot; assignable
Z
global, shared, kept from one press to the next, 0 at boot; assignable
T
global, shared, kept from one press to the next, 0 at boot; assignable
I
counter of the innermost loop (L, EACH); read-only, 0 outside loops
J
counter of the loop above the innermost one; read-only, 0 outside loops

State

FLIP
alternates 0, 1, 0... on each read; FLIP x sets it
O
counter, moves by O.INC after each read, between O.MIN and O.MAX; O x sets it
O.MIN x
lowest value of O (default 0) statement
O.MAX x
highest value of O (default 63) statement
O.WRAP x
1 = O wraps around at its limits (default), 0 = it stops statement
O.INC x
step of O after each read (default 1) statement
DRUNK
random walk: moves by -1, 0 or +1 on each read; DRUNK x sets it
DRUNK.MIN x
lowest value of DRUNK (default 0) statement
DRUNK.MAX x
highest value of DRUNK (default 127) statement
DRUNK.WRAP x
1 = DRUNK wraps around at its limits, 0 = it stops (default) statement

Maths

SUB x y-
subtract y from x
MUL x y*
multiply x by y
DIV x y/
divide x by y (0 if y is 0)
MOD x y
remainder of x / y, never negative (0 if y is 0)
MIN x y
the smaller of x and y
MAX x y
the larger of x and y
ABS x
absolute value of x
NEG x
x with its sign flipped
LIM x lo hi
clamp x into lo..hi
WRAP x lo hi
wrap x around into lo..hi

Logic

NOT x
1 if x is 0, else 0
EQ x y==
1 if x equals y
NE x y!=
1 if x differs from y
LT x y<
1 if x is less than y
GT x y>
1 if x is greater than y
LE x y<=
1 if x is less than or equal to y
GE x y>=
1 if x is greater than or equal to y
AND x y
1 if x and y are both true (both are evaluated)
OR x y
1 if x or y is true (both are evaluated)
XOR x y
1 if exactly one of x and y is true
EZ x
1 if x is 0
NZ x
1 if x is not 0

Lists and values

? c a b
a if c is true, else b (only the chosen one is evaluated)
AT list i
i-th element of a list (1..n, clamped)
LEN list
number of elements of a list
ON
the value 1
OFF
the value 0

Randomness

RND n
random number 0..n-1
RRAND a b
random number a..b inclusive
TOSS
random 0 or 1
CHANCE p
1 with p percent probability, else 0
PICK list
random element of a list

Rhythm

ER k n s
1 if step s plays in a Euclidean rhythm of k hits over n steps
ER.R k n r s
like ER, with the rhythm rotated by r steps
DR.V c s
velocity 0..127 of curve c (accents, off-beats, ramps) at step s

Context

TRK.CUR
the current track number
STEP.CUR
the current step number
TRK t...
act on tracks t... (or CUR, or ALL)
STEPS ALL|a b|PRED
act on ALL steps, steps a..b, or the steps matching a predicate (HAS.TRIG)
STEP s
act on step s only
SEED n
reproducible randomness from here on: seeds all five streams
RAND.SEED n
seed the random stream of RND, RRAND and PICK only
TOSS.SEED n
seed the random stream of TOSS and CHANCE only
PROB.SEED n
seed the random stream of the PROB modifier only
DRUNK.SEED n
seed the random stream of DRUNK only
FILE.SEED n
seed the random stream of FILE.RND, FILE.PICK and SLOTS.RND only

Trigs

PAT.LEN
length of the current pattern
HAS.TRIG s
1 if step s has a trig predicate
IS.EMPTY s
1 if step s has no trig and no lock predicate
TR.ADD s
add a trig on step s
TR.DEL s
remove the trig on step s
TR.FLIP s
toggle the trig on step s
TR.CLR
remove every trig of the current steps destructive
TL.ADD s
add a trigless lock trig on step s
TL.FILL p
fill the current steps with trigless locks, p percent of them

Trig word

COND.SET s c
set the trig condition of step s
COND.RND c d
random trig conditions between c and d on the current steps
MICRO.SET s x
set the micro-timing offset x of step s
MICRO.RND x
random micro-timing up to x on the current steps
RATCH s x
set x retriggers on step s

Card

list the files of a card folder (DEEP: with subfolders) statement

FILE.PICK

SLOTS.RND
