# OType docs

Published reference for **OType**, scripting for the Elektron Octatrack:
https://nordseele.github.io/otype-docs/

The pages are generated in the [OType repository](https://github.com/nordseele/otype) by
`python3 tools/site.py ../otype-docs`: `index.html` (the reference), `learn/`, `cookbook.html` and `style.css`,
the one stylesheet (edit `tools/site.css` there). `roadmap.html` is kept by hand and links the same `style.css`.
